# Source audit

Read the exact cited statement and the part of its proof on which the application depends. Match the hypotheses and conventions to the project’s objects. Check whether a later version or erratum changes the argument.

Record the version, locator, specialization and any unmet obligation in `references/KEY/audit/` under the [reference conventions](../../../references/README.md). A reader should be able to verify the application from that record.
