# Research and review roles

Read [PROTOCOL.md](PROTOCOL.md) for the acceptance process.

Roles are bounded responsibilities, not a standing team:

- [Author](roles/author.md): complete an argument and polish the integrated candidate.
- [Proof verifier](roles/proof-verifier.md): independently check the exact final claim and its support.
- [Counterexample reviewer](roles/counterexample.md): attack assumptions and boundary cases.
- [Source auditor](roles/auditor.md): match primary-source hypotheses and retain exact locators.
- [Style referee](roles/style-referee.md): assess ambiguity, economy, clarity, notation, citations and rendered presentation.

Start assignments from [task.md](templates/task.md); return [review.md](templates/review.md).
Exploration and maintenance normally use one agent. Independent draft review calls for fresh contexts and disjoint review outputs.
Keep mathematical disagreement visible; a majority vote cannot repair a gap.
