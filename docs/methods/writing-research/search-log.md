# Search log and coverage

Date: 2026-11-15. Four actual workers: primary integrator/AI instructions; human-writing survey; empirical-agent survey; exemplars/referees survey. Additional passes broadened specialist exemplars and checked source alignment. These were discovery/research assignments, not independent draft verification.

## Method

1. Read `workflow/CURRENT.md`, `notes/README.md`, the current `writing-style.md`, reference-corpus requirements and relevant agent roles/protocol.
2. Divide the user's four categories into exclusive topic files.
3. Search broad phrases, then follow author pages, official publisher records, primary texts, original repositories and citations.
4. Read selected substantive passages in high-priority sources; mark abstracts, metadata, access failures and leads explicitly.
5. Compare independent source families and identify conflicting preferences rather than counting all advice as consensus.
6. Integrate recommendations for this repository, write a proposed replacement and concrete job briefs, and check alignment against the sources and existing proof-review rules.
7. Validate local links, source-ID index, JSON, ignored status, unchanged active policy, and repository checks.

The initial author-credential filter was removed after the user's clarification. Intended use in publishable mathematical research is decisive. Competition/homework resources remain excluded from the main style shortlist; empirical competition-proof studies are retained only as explicitly indirect evidence.

## Scope and limits

- 117 numbered entries plus additional leads. Multiple documents from one author, related implementations and editions are separate entries; this is not a count of independent studies or endorsements.
- English dominates; Audin supplies a French source, and Ishiki's bilingual materials broaden coverage. This is not a multilingual systematic review.
- Some books were inspected through publisher descriptions or excerpts, some original texts through selected sections, and some references only as leads. No cover-to-cover reading is implied by source inclusion.
- GitHub branch URLs and live reference tags are mutable. Access dates and observed sections are recorded; exact original payloads and hashes were not retained.
- No finite search proves internet exhaustiveness. Private skills, unindexed Markdown and newly revised material can be missed.
- “Best written” is not an objective total ordering. Awards and praise substantiate reputation only within their actual scope. Author-level lifetime awards are not silently converted to article-specific awards.
- No experiment here demonstrates an optimal agent team for pure mathematical publication prose. Scientific-paper trials, short-proof benchmarks, practitioner workflows and our proposals have different evidential roles.

## What would extend this survey usefully

Prioritize reading the marked high-relevance leads and unavailable chapters, pin chosen implementations before adoption, and acquire source payloads/metadata under the repository's corpus rules if building a permanent literature collection. A local comparison on actual research drafts is more decision-relevant than indiscriminately collecting another hundred generic writing prompts.
